# CyberFlipper Level 011-099 Expansion Map

CyberFlipper should fill every level with a clear skill, output, and review requirement.

## Expansion Standard

Each level should include a README, at least one platform `.txt` file, a visible `cyberflipper_` output file, defensive notes, and a review note.

## Level Bands

| Band | Theme | Output style |
|---|---|---|
| 011-019 | Workstation basics | Authorization, user context, network, browser, software, update, and backup worksheets. |
| 020-029 | IR triage | Process review, listener review, event counts, patch posture, and report manifests. |
| 030-039 | Patch and exposure | Patch SLA worksheets, vendor watch cards, exposure scoring, and remediation notes. |
| 040-049 | Firmware and app review | Firmware changes, app catalog review, SD-card provenance, and USB/HID policy notes. |
| 050-059 | Evidence discipline | Hash manifests, collection notes, handoff forms, and chain-of-custody worksheets. |
| 060-069 | SBOM and provenance | SD-card inventory, file manifests, source attribution, release review, and lint rules. |
| 070-079 | Change intake | Risky-source conversion, change review, issue templates, and release gates. |
| 080-089 | Sandbox readiness | Local lab readiness, VM notes, safe sample-handling worksheets, and mitigation plans. |
| 090-099 | Capstone release | Evidence communications, release gate, final validation, maintainer review, and public notes. |
