# CyberFlipper Level 017 - Backup and Sync

Purpose: document backup and sync coverage so recovery can be tested before an incident.

Expected artifact: `cyberflipper_l017_backup_sync`.

Safe tasks:

- Record backup provider or local backup method.
- Record sync folders by policy name, not private file contents.
- Record last known recovery-test date when available.
- Record retention and restore owner.
- Record gaps requiring follow-up.

Do not browse personal files, copy data, open private folders, extract cloud tokens, or modify backup jobs.

Human review is required before adding executable backup-status commands.
