# CyberFlipper Level 012 - Host Context

Purpose: document basic authorized host context for defensive inventory and review.

Expected artifact: `cyberflipper_l012_host_context`.

Safe tasks:

- Record hostname or asset tag when authorized.
- Record operating system family and version.
- Record logged-in operator identity as a self-attested field.
- Record business owner and support contact.
- Record whether the device is personal, lab, production, or shared.

Do not collect secrets, private documents, browser stores, tokens, passwords, cookies, or unrelated user data.

Human review is required before adding executable host-inventory commands.
