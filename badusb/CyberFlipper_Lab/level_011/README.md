# CyberFlipper Level 011 - Operator Scope Card

Purpose: establish authorization, test window, asset owner, and expected artifact location before any hands-on HID or host-facing lab work.

Expected artifact: `cyberflipper_l011_scope_card`.

Safe tasks:

- Record operator name and organization.
- Record written scope reference.
- Record test start and end time.
- Record asset owner and device used.
- Record expected local output path.

Do not collect credentials, browser data, tokens, cookies, private files, or third-party system data.

Human review is required before adding executable BadUSB text for this level.
