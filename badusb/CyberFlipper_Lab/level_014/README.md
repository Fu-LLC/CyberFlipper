# CyberFlipper Level 014 - Browser Posture

Purpose: document browser update posture and policy review without touching user secrets.

Expected artifact: `cyberflipper_l014_browser_posture`.

Safe tasks:

- Record installed browser names by operator observation.
- Record whether each browser is current, outdated, or unknown.
- Record extension-review owner and policy reference.
- Record whether password-manager policy is documented.
- Record follow-up actions for unsupported browsers.

Do not read browser history, cookies, saved passwords, autofill data, sessions, or profiles.

Human review is required before adding executable browser inventory commands.
