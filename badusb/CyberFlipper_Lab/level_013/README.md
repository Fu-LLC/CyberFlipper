# CyberFlipper Level 013 - Network Context

Purpose: create a defensive network-context worksheet for an authorized host.

Expected artifact: `cyberflipper_l013_network_context`.

Safe tasks:

- Record network owner and authorized scope.
- Record interface names and whether they are wired, wireless, VPN, or virtual.
- Record DNS and gateway review notes.
- Record whether unexpected listening services require follow-up.
- Record escalation path for suspicious findings.

Do not scan third-party networks, attempt access, capture credentials, crack Wi-Fi, or transmit RF.

Human review is required before adding executable network commands.
