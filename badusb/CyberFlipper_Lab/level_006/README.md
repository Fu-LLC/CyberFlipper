# CyberFlipper Level 006 - Community Desktop Review Suite

Level 006 adds visible local reporting scripts for Windows, Linux, and macOS.

## Files

- `cf_l006_windows_desktop_stack_audit.txt`
- `cf_l006_windows_browser_review.txt`
- `cf_l006_linux_desktop_stack_audit.txt`
- `cf_l006_macos_workstation_review.txt`

## Output

Each script writes a local `cyberflipper_l006_` report and opens it for review.

## Review

Review before publication. These scripts are report-only and intended for authorized lab systems.
